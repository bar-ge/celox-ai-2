Celox AI — Design System

Extracted from the live fleet-management app. Plum & cream neutrals, one blue→indigo accent, Heebo, RTL-first. Source of truth: src/fleet-manager.jsx (C) and src/index.css.

Color

Neutrals are warm (plum ink on cream), never pure gray. The accent gradient is reserved for primary actions and the logo mark.

RTL first. Hebrew is the primary locale; every layout must mirror cleanly. Use logical CSS properties (margin-inline-start, text-align:start) and place icon affordances on the side text runs away from — e.g. the password-reveal eye sits left in RTL, right in LTR.
