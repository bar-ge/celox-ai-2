# מרשם פעילויות עיבוד (RoPA)

**מזהה מסמך:** AMD13-ROPA-001
**גרסה:** 1.0
**תאריך:** 2026-07-08
**בעלים:** ממונה על הגנת הפרטיות
**מעמד:** טיוטה — לאמת מול עו"ד; לרענן בכל שינוי מהותי במערכת

---

> **הבהרה:** מסמך זה אינו ייעוץ משפטי. הבסיס החוקי לכל פעילות `[לאימות עו"ד]`.

## 1. מטרה

לתעד את כל פעילויות עיבוד המידע האישי במערכת Celox AI — סוגי מידע, מטרות, נושאי מידע, שמירה, וזרימה — כנדרש בתיקון 13.

## 2. בקר ומעבד

| תפקיד | גורם |
|-------|------|
| בקר המידע (Controller) | חברת הלקוח (בעלת הצי) עבור מידע הנהגים; Celox AI עבור מידע ה-CRM/לידים |
| מעבד המידע (Processor) | Celox AI Ltd. (עבור מידע הלקוחות) |
| מעבדי משנה (Sub-processors) | Supabase (אחסון/DB, טוקיו) · Vercel (אירוח, EU/US) · Cloudflare (Turnstile/CDN) · Resend (אימייל) |

## 3. פעילויות עיבוד

### 3.1 ניהול נהגים

| שדה | ערך |
|-----|-----|
| מטרה | ניהול צי — שיוך נהגים לרכבים, מעקב רישיונות, ציות |
| נושאי מידע | נהגים המועסקים אצל לקוחות Celox |
| סוגי מידע | שם, ת"ז (במספר רישיון), מספר רישיון + רמות, טלפון, תוקף רישיון, שיוך סניף, הסכמה (`consent_given_at`) |
| רגישות | מידע אישי; מספר רישיון עשוי להיחשב מזהה רגיש `[לאימות עו"ד]` |
| בסיס חוקי | הסכמה + צורך ניהולי לגיטימי של המעסיק `[לאימות עו"ד]` |
| שמירה | למשך ההתקשרות + תקופה חוקית `[למילוי]` |
| מיקום אחסון | Supabase (טוקיו) |

### 3.2 ניהול רכבים ותחזוקה

| שדה | ערך |
|-----|-----|
| מטרה | מעקב רכבים, טיפולים, קילומטראז', מסמכים |
| נושאי מידע | — (נתוני רכב; מקושר לנהג המשויך) |
| סוגי מידע | לוחית, יצרן/דגם, ק"מ, סטטוס, מסמכים (ביטוח/רישוי/טסט) |
| בסיס חוקי | צורך תפעולי |

### 3.3 דוחות תאונה

| מטרה | תיעוד אירועי תאונה וניהול תביעת ביטוח |

| סוגי מידע | פרטי נהג, פרטי צד ג', תיאור, קבצים מצורפים, פרטי פוליסה/תביעה |
| רגישות | כולל מידע על צד ג' שאינו לקוח — לשים לב לבסיס החוקי `[לאימות עו"ד]` |
| מיקום אחסון | Supabase (טוקיו) + קבצים |
