## 1. תיאור המערכת

Celox AI היא פלטפורמת SaaS לניהול צי רכבים. המערכת מאחסנת:
- נתוני עובדים/נהגים (שם, טלפון, רישיון)
- נתוני רכבים (לוחית, היסטוריית תחזוקה)
- נתוני משתמשים (אימייל, תפקיד, פעילות)

**ספקי תשתית:** Supabase (DB + Auth), Vercel (Hosting), Resend (Email)
**מיקום נתונים:** שרתי ענן בארה"ב עם הסכמי DPA

---

## 2. בקרת גישה

### 2.1 עקרונות
- כל משתמש מקבל **רק** את ההרשאות הנדרשות לתפקידו (Least Privilege)
- גישת מנהל (Admin) — לבעלי חברה בלבד
- גישת חבר (Member) — לעובדים רגילים

### 2.2 ניהול סיסמאות
- סיסמה מינימלית: 8 תווים + אות גדולה + מספר + תו מיוחד
- נאכף טכנית ע"י המערכת בעת הרשמה
- אין שמירת סיסמאות בטקסט גלוי — הצפנה מלאה ע"י Supabase Auth

### 2.3 הרשאות מנהל מערכת
- גישת root/master — לבר גרשנזון בלבד
- מפתחות API מאוחסנים ב-Supabase Secrets בלבד (לא בקוד)

---

## 3. אבטחה טכנית

| בקרה | יישום |
|------|-------|
| הצפנת תעבורה | HTTPS/TLS 1.2+ בכל נקודות הגישה |
| הצפנת אחסון | Supabase AES-256 at-rest |
| RLS | Row Level Security פעיל בכל הטבלאות |
| CAPTCHA | hCaptcha בדף הכניסה |
| גיבויים | Supabase — גיבוי אוטומטי יומי |
| לוג פעילות | כל פעולה מתועדת ב-activity_log |

---

## 4. ניהול גישה של צדדים שלישיים

- ספקי ענן (Supabase/Vercel/Resend) — גישה מוגבלת למטרת השירות בלבד
- לא מועבר מידע אישי לגורמים שלישיים ללא הסכם DPA
- עובד/קבלן חדש — מקבל הרשאות מינימליות, ומוסר חשבון בעת סיום עבודה

---

## 5. תגובה לאירוע אבטחה (פרצת מידע)

### שלב 1 — זיהוי (0-4 שעות)
- בלם את הגישה הלא מורשית (שנה סיסמאות / בטל מפתחות)
- תעד: מה קרה, מתי, אילו נתונים נחשפו, כמה אנשים מושפעים

### שלב 2 — הערכה (4-24 שעות)
- האם מדובר ב"אירוע אבטחה חמור"? (גישה לא מורשית / דליפה / השמדת נתונים)
- אם כן — חובה לדווח לרשות להגנת הפרטיות

### שלב 3 — דיווח (ללא דיחוי)
- **לרשות להגנת הפרטיות:** gov.il/he/departments/privacy_authority
- **לנושאי המידע המושפעים:** אם הפרצה עלולה לגרום להם נזק

### שלב 4 — תיקון ותיעוד
- תקן את הפגיעות
- תעד את כל האירוע, הפעולות שנקטת, והלקחים

## 6. הגנה פיזית

- המערכת פועלת בענן — אין שרתים פיזיים במשרד
- גישה ל-dashboard הניהולי — ממחשבים מאובטחים בלבד
- לא לפתוח גישת admin מרשת Wi-Fi ציבורית

## 7. סקירה שנתית

הממונה על אבטחת המידע יבצע סקירה שנתית הכוללת:
- בדיקת הרשאות כל המשתמשים
- עדכון מפתחות ו-secrets במידת הצורך
- עדכון מסמך זה
- בדיקת DPA עם ספקים
