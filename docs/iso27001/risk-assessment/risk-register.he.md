### RISK-003 — דליפת מידע חוצת-חברות (עקיפת RLS)

| שדה | ערך |
|-----|-----|
| **נכס** | כל נתוני חברות הלקוח |
| **איום** | באג במדיניות RLS מאפשר לחברה א' לגשת לנתוני חברה ב' |
| **פגיעות** | מדיניות SQL שגויה; WHERE חסר; שימוש לרעה בפונקציית SECURITY DEFINER |
| **סבירות** | 2 — נמוכה (המדיניות פשוטה ונבדקת) |
| **השפעה** | 5 — קריטית (דליפת כל נתוני הלקוחות; נזק אמון קטסטרופלי) |
| **סיכון מובנה** | 10 — 🟠 גבוה |
| **בקרות נוכחיות** | `my_company_id()` נאכף בכל מדיניות RLS; `is_master()` לעקיפת מנהל בלבד; סקירת קוד בכל שינוי סכימה |
| **טיפול** | הפחתה |
| **בקרות מתוכננות** | בדיקה אוטומטית: ניסיון שאילתה על נתוני חברה ב' מסשן חברה א' ואימות 0 שורות |
| **סיכון שיורי** | 4 — 🟢 נמוך |
| **בעלים** | בר גרשונזון |
| **תאריך יעד** | 2026-09-30 |
