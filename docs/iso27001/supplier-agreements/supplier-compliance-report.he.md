## 3. הערכות ספק מפורטות

### 3.1 Supabase Inc.
**שירות:** מסד נתונים PostgreSQL, אימות, Edge Functions, אחסון
**סיווג:** דרגה 1 — קריטי (מאחסן את כל המידע האישי של הלקוחות)

**הסמכות שאומתו:** SOC 2 Type II ✅ · ISO 27001 ✅ · HIPAA ✅ (עם BAA).

**בקרות אבטחה:** הצפנה במנוחה AES-256 · הצפנה במעבר TLS · MFA מופעל בחשבוננו · RBAC דרך RLS · הגנת DDoS דרך Cloudflare · גיבויים יומיים עם PITR · מבחני חדירה סדירים של Supabase · סריקת פגיעויות (GitHub, Vanta, Snyk).

**עיבוד מידע:** מאחסן מידע אישי — כל נתוני הנהגים, GPS והחברות. מיקום: תשתית AWS (אזור לאימות). DPA/GDPR זמין ומקובל.

**הערכת סיכון:** נמוך — פלטפורמה מבוססת עם עמידה חזקה. שכבת ה-RLS מוסיפה הגנה מעבר לבקרות של Supabase.

### 3.2 Vercel Inc.
**שירות:** אירוח frontend, פונקציות serverless, CI/CD, ניהול משתני סביבה
**סיווג:** דרגה 1 — קריטי (מאחסן קוד אפליקציה; מנהל סודות ייצור)

**הסמכות שאומתו:** ISO 27001:2013 ✅ · SOC 2 Type II ✅ · PCI DSS v4.0 ✅ · GDPR ✅ · TISAX רמה 2 ✅.

**בקרות אבטחה:** הצפנה במנוחה AES-256 · HTTPS/TLS · גיבויים אוטומטיים כל שעתיים, שמירה 30 יום, משוכפל גלובלית · משתני סביבה מוצפנים · אכיפת HTTPS.

**עיבוד מידע:** משתני סביבה (מפתחות API) ו-build artifacts. מידע אישי של לקוחות — אינו מאוחסן ישירות (מוגש דרך קריאות API ל-Supabase). DPA מקובל.

**הערכת סיכון:** נמוך — עמידה שעולה על דרישות Celox AI.

### 3.3 Cloudflare Inc.
**שירות:** ניהול DNS, CDN, WAF, Turnstile CAPTCHA
**סיווג:** דרגה 2 — חשוב

**הסמכות שאומתו:** ISO 27001 ✅ · ISO 27701 ✅ (ניהול מידע פרטיות) · SOC 2 Type II ✅ · PCI DSS ✅.

**בקרות אבטחה:** הגנת DDoS מובילה · WAF · TLS ב-edge · Turnstile (זיהוי בוטים משמר-פרטיות, ללא cookies).

**עיבוד מידע:** מטא-דאטה של בקשות HTTP (כתובות IP) ל-WAF/DDoS. מידע אישי של לקוחות — אינו מאוחסן (תעבורה עוברת בלבד). DPA מקובל.

**הערכת סיכון:** נמוך — מתווך תעבורה טהור ללא אחסון נתונים.

### 3.4 GitHub (Microsoft)
**שירות:** מאגר קוד, CI/CD דרך GitHub Actions, אירוח תיעוד ISMS
**סיווג:** דרגה 2 — חשוב

**הסמכות שאומתו:** ISO 27001 ✅ · SOC 2 ✅ · GDPR ✅.

**בקרות אבטחה:** קוד מוצפן במנוחה ובמעבר · סריקת סודות מופעלת · Dependabot מופעל · MFA נאכף · הגנת ענף `main`.

**עיבוד מידע:** ללא מידע אישי (קוד מקור בלבד). מסמכי ISMS — ציבוריים בלבד (ללא סודות).

**הערכת סיכון:** נמוך.

### 3.5 Google LLC (OAuth)
**שירות:** ספק כניסה Google OAuth 2.0 · דרגה 2.
**הסמכות:** ISO 27001 ✅ · SOC 2 ✅.
**עיבוד מידע:** אימייל, שם ותמונת פרופיל של חשבון Google (בהסכמה). מידע אישי של לקוחות אינו נשלח ל-Google.
**הערכת סיכון:** נמוך.

### 3.6 Microsoft (Azure AD OAuth)
**שירות:** ספק כניסה Microsoft OAuth 2.0 / Azure AD · דרגה 2.
**הסמכות:** ISO 27001 ✅ · SOC 2 ✅ · GDPR ✅.
**עיבוד מידע:** אימייל ושם של חשבון Microsoft (בהסכמה). מידע אישי של לקוחות אינו נשלח.
**הערכת סיכון:** נמוך — פרופיל זהה ל-Google OAuth.

## 5. מסקנה

כל ספקי דרגה 1 ו-2 עומדים או עולים על דרישות האבטחה המינימליות של Celox AI כמוגדר במדיניות ניהול הספקים (ISMS-POL-008). כל הספקים הקריטיים מחזיקים הסמכות ISO 27001 ו/או SOC 2 Type II תקפות, מספקים הצפנה במנוחה ובמעבר, ובעלי הסכמי עיבוד נתונים תואמי-GDPR.
